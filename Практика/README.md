# Практика

Файлы, которые раздаются на занятиях: заготовки кода, сценарии n8n, данные для лабораторных. Папку ведёт преподаватель. Новые файлы GitHub переносит сюда раз в сутки (см. [docs/UPDATES.md](https://github.com/gkfosl/sysprog-start-template/blob/main/docs/UPDATES.md)). Свои файлы в эту папку не кладите: при обновлении они не удалятся, но их перепутают с раздаточными.
