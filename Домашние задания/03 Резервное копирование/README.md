# Кейс 03. Резервное копирование

Программа создаёт ZIP-копию документов, сверяет SHA-256 файлов и сохраняет архив только после проверки. В сценарии созданы три версии. Из T0 и T1 восстановлены документы, удалённые на следующих этапах.

- [Отчёт в PDF](Отчёт.pdf)
- [Программа](backup.py)
- [Журнал проверки](Журнал.txt)

![Создание трёх архивов, восстановление T0 и T1 и проверка повреждённого архива](Снимок%20проверки.jpg)

Для повторения положите `backup.py` рядом с файлом `scenario.py` из учебного архива. Команды и результаты приведены в журнале.
